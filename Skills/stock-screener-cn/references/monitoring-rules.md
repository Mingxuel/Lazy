# 持仓监控预警规则

> 持仓股的异动监控与预警规则，适用于 A 股趋势/短线交易风格。

---

## 一、监控维度总览

```
技术信号预警 + 资金异动预警 + 事件触发预警 + 基本面预警
```

短线持仓监控重点：**及时捕捉卖出信号和风险事件**。

---

## 二、技术信号预警（卖出信号）

### 2.1 指标死叉

监控条件：持仓股出现 MACD/KDJ 死叉

```bash
# 获取持仓股K线数据判断
westock-data kline <代码> --period day --limit 10
```

预警级别：
- **MACD死叉**：⚠️ 中级卖出信号，考虑减仓
- **KDJ死叉（J值>80）**：⚠️ 超买区死叉，短期调整信号
- **MACD柱状图缩短**：💡 趋势减弱，关注变化

### 2.2 均线破位

监控条件：股价跌破关键均线

预警级别：
- **跌破MA5**：💡 短线走弱信号
- **跌破MA10**：⚠️ 短线趋势破坏
- **跌破MA20**：🔴 强势卖出信号，止损线
- **跌破MA60**：🔴 中线趋势破坏，果断离场

### 2.3 量价异常

监控条件：成交量和价格出现异常组合

预警级别：
- **放量滞涨**：⚠️ 主力可能出货
- **放量下跌**：🔴 资金出逃，果断止损
- **缩量上涨**：💡 上涨动力不足
- **天量天价**：🔴 阶段顶部信号

### 2.4 形态破位

预警级别：
- **跌破上升趋势线**：⚠️ 趋势反转信号
- **跌破平台支撑**：🔴 破位下行信号
- **双顶/头肩顶**：🔴 见顶形态

## 三、资金异动预警

### 3.1 主力资金流出

```bash
westock-data fund flow <代码>
```

预警级别：
- **单日主力净流出>流通市值2%**：⚠️ 资金撤退信号
- **连续3日主力净流出**：🔴 趋势性出逃
- **主力净流出放大**：🔴 加速出逃

### 3.2 龙虎榜异动

```bash
westock-tool event longhu_statis_past_15
westock-data lhb --type institution
```

预警级别：
- **持仓股上榜且机构净卖出**：🔴 机构出货信号
- **持仓股上榜且游资买入**：💡 短线活跃，关注持续性

### 3.3 大宗交易异动

```bash
westock-tool event block_past_30
westock-data fund block <代码>
```

预警级别：
- **折价大宗交易**：⚠️ 可能减持套现
- **频繁大宗交易**：💡 关注股东动向

## 四、事件触发预警

### 4.1 减持/解禁事件

```bash
westock-tool event manager_sharechg          # 董监高增减持
westock-tool event manager_shareplan_sell_incoming  # 计划减持
westock-tool event shareunlock_next_90       # 近90天解禁
westock-tool event shareunlock_incoming      # 实际解禁
```

预警级别：
- **董监高减持公告**：🔴 利空信号，考虑减仓
- **计划减持**：⚠️ 未来抛压，警惕
- **限售解禁**：⚠️ 短期抛压，关注解禁规模
- **大股东质押**：⚠️ 强平风险

### 4.2 业绩事件

```bash
westock-tool event earnings_forecast         # 业绩预告
westock-tool event earnings_schedule         # 业绩预约披露
westock-tool event earnings_release          # 业绩披露
```

预警级别：
- **业绩预减/预亏**：🔴 重大利空，果断离场
- **业绩低于预期**：⚠️ 调整风险
- **业绩超预期**：💡 利好催化，可加仓

### 4.3 风险事件

```bash
westock-data risk <代码>
westock-data events tags <代码>
```

预警级别：
- **ST/退市风险**：🔴 立即清仓
- **违规/处罚**：🔴 黑天鹅风险
- **诉讼**：⚠️ 不确定性增加
- **商誉减值**：🔴 业绩暴雷风险

### 4.4 停复牌

```bash
westock-data suspension --market hs
```

预警级别：
- **临停**：💡 关注停牌原因
- **重大事项停牌**：⚠️ 不确定性
- **复牌**：💡 关注补涨/补跌

## 五、基本面预警

### 5.1 评级变动

```bash
westock-data consensus <代码>
```

预警级别：
- **机构评级下调**：⚠️ 机构看空
- **目标价大幅下调**：⚠️ 上涨预期降低
- **一致预期EPS下调**：⚠️ 业绩预期恶化

### 5.2 评分变动

```bash
westock-data score <代码>
```

预警级别：
- **综合评分下降>10分**：⚠️ 质地恶化
- **风险评分上升**：⚠️ 风险增加

---

## 六、监控执行流程

### 6.1 日常监控（每日盘后）

1. **技术检查**：`westock-data kline <持仓代码批量> --period day --limit 10` → 检查指标/均线/量价
2. **资金检查**：`westock-data fund flow <持仓代码批量>` → 检查主力资金动向
3. **事件检查**：`westock-tool event manager_sharechg,shareunlock_incoming,earnings_forecast` → 检查事件触发
4. **风险检查**：`westock-data risk <持仓代码批量>` → 检查风险事件

### 6.2 预警分级响应

| 级别 | 含义 | 响应动作 |
|------|------|----------|
| 🔴 高危 | 明确卖出信号 | 次日开盘减仓/清仓 |
| ⚠️ 中危 | 风险信号出现 | 密切关注，准备减仓 |
| 💡 提示 | 异常变化 | 记录观察，持续跟踪 |

### 6.3 报告生成

监控完成后，按 `assets/report-monitoring.md` 模板生成预警报告，包含：
1. 持仓概览
2. 各维度预警结果
3. 预警分级汇总
4. 建议操作
5. 下一步监控重点
