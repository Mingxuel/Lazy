# 个股深度分析框架

> 四维度个股深度分析流程，适用于 A 股趋势/短线交易风格。每个维度映射到具体数据查询命令。

---

## 分析流程总览

```
技术面（趋势/买卖点）→ 资金面（主力动向）→ 基本面（排雷/质地）→ 消息面（催化剂）
         ↓                    ↓                   ↓                   ↓
     K线/指标              资金流向            财务/估值            公告/研报
         ↓                    ↓                   ↓                   ↓
                    综合评估 → 操作建议
```

短线交易权重：技术面 40% + 资金面 30% + 消息面 20% + 基本面 10%

---

## 一、技术面分析（权重40%）

### 1.1 趋势判断

```bash
# 获取60日K线（含MA5/MA10/MA20/MA60）
westock-data kline sh600519 --period day --limit 60
```

分析要点：
- **多头排列**：MA5 > MA10 > MA20 > MA60，趋势向上
- **空头排列**：MA5 < MA10 < MA20 < MA60，趋势向下
- **均线粘合**：各均线趋近，面临方向选择
- **站上/跌破MA20**：短线强弱分界线

### 1.2 技术指标

K线命令返回含 MACD/KDJ/RSI/布林带，分析要点：

| 指标 | 看涨信号 | 看跌信号 |
|------|----------|----------|
| MACD | DIF上穿DEA（金叉）、柱状图由绿转红、零轴上方 | DIF下穿DEA（死叉）、柱状图由红转绿、零轴下方 |
| KDJ | J值<20超卖区回升、K线上穿D线金叉 | J值>80超买区回落、K线下穿D线死叉 |
| RSI | RSI<30超卖反弹、RSI上穿50 | RSI>70超买回落、RSI下穿50 |
| 布林带 | 触及下轨反弹、突破上轨放量 | 触及上轨回落、跌破中轨 |

### 1.3 K线形态

| 形态 | 含义 |
|------|------|
| 早晨之星 | 底部反转信号 |
| 红三兵 | 上升趋势确立 |
| 放量突破 | 突破阻力位，看涨 |
| 缩量回调 | 上升趋势中健康回调 |
| 长上影线 | 上方压力较大 |
| 长下影线 | 下方支撑较强 |

### 1.4 买卖点判断

- **买点**：金叉确认 + 放量突破 + 站上关键均线
- **卖点**：死叉确认 + 放量滞涨 + 跌破关键均线
- **止损**：跌破MA20或近期低点
- **止盈**：触及布林带上轨 + RSI超买 + 放量滞涨

## 二、资金面分析（权重30%）

### 2.1 主力资金流向

```bash
westock-data fund flow sh600519
```

分析要点：
- **主力净流入为正且持续**：资金积极介入，看涨
- **主力净流出且放大**：资金撤退，警惕
- **散户净流入为主**：主力未参与，谨慎
- **连续多日净流入**：趋势性资金介入

### 2.2 龙虎榜（游资/机构动向）

```bash
# 机构席位
westock-data lhb --type institution

# 查特定股是否上榜（通过事件选股）
westock-tool event longhu_statis_past_15
```

分析要点：
- **机构净买入**：机构看好，中线信号
- **游资席位频繁出现**：短线活跃度高
- **机构卖出**：警惕中线风险

### 2.3 大宗交易

```bash
westock-data fund block sh600519
westock-tool event block_past_30
```

分析要点：
- **溢价大宗交易**：买方看好，积极信号
- **折价大宗交易**：可能减持套现，谨慎
- **频繁大宗交易**：关注股东动向

### 2.4 筹码分布

```bash
westock-data chip sh600519
```

分析要点：
- **筹码集中度高**：主力控盘，趋势性强
- **筹码分散**：散户为主，难有大行情
- **获利盘比例高**：上方抛压小，上涨阻力小
- **获利盘比例低**：套牢盘多，反弹遇阻

## 三、基本面分析（权重10%）

短线交易基本面主要用于排雷，不追求深度价值分析。

### 3.1 财务健康度

```bash
westock-data finance sh600519
```

排雷指标：
- **净利润为负**：亏损股，警惕
- **营收大幅下滑**：经营恶化，警惕
- **资产负债率>70%**：高负债风险
- **经营现金流为负**：现金流恶化

### 3.2 估值水平

```bash
westock-data quote sh600519   # 行情快照含PE/PB
westock-data finance sh600519 # 财报含详细估值
```

短线估值参考：
- **PE_TTM > 0 且 < 100**：估值合理范围（短线不苛求低估值）
- **PE_TTM 为负**：亏损，排雷
- **PB < 1**：破净，可能有估值修复机会

### 3.3 风险事件

```bash
westock-data risk sh600519
```

重点排查：
- **高质押率（>50%）**：大股东质押风险
- **ST/退市风险**：直接排除
- **商誉占净资产比例高**：减值风险
- **诉讼/违规**：黑天鹅风险

### 3.4 机构评级与一致预期

```bash
westock-data consensus sh600519
westock-data score sh600519
```

分析要点：
- **机构评级上调**：利好催化
- **一致预期EPS上调**：业绩预期改善
- **综合评分>70**：质地较好

## 四、消息面分析（权重20%）

### 4.1 公告事件

```bash
westock-data notice list sh600519 --limit 10
westock-data events tags sh600519
```

重点关注：
- **业绩预告/快报**：超预期或低于预期
- **回购/增持公告**：利好信号
- **减持公告**：利空信号
- **重组/并购**：重大催化
- **限售解禁**：短期抛压

### 4.2 研报观点

```bash
westock-data report list sh600519 --limit 5
westock-data dehydrated list
```

分析要点：
- **券商集中推荐**：市场关注度提升
- **评级上调**：机构看好
- **目标价上调**：上涨空间预期

### 4.3 新闻资讯

```bash
westock-data news article sh600519 --limit 10
westock-data news market --market hs
```

分析要点：
- **行业政策利好**：板块催化
- **公司正面新闻**：短期催化
- **负面舆情**：规避风险

### 4.4 事件驱动

```bash
# 近期事件触发
westock-tool event earnings_forecast     # 业绩预告
westock-tool event buyback               # 回购
westock-tool event shareunlock_next_90   # 近期解禁
westock-tool event manager_sharechg      # 董监高增减持
```

## 五、综合评估与操作建议

### 5.1 信号强度评分

| 维度 | 强势信号 | 弱势信号 |
|------|----------|----------|
| 技术面 | 金叉+多头排列+放量突破 | 死叉+空头排列+放量下跌 |
| 资金面 | 主力连续净流入+机构买入 | 主力持续流出+机构卖出 |
| 消息面 | 业绩超预期+回购+政策利好 | 减持+解禁+负面舆情 |
| 基本面 | 评分>70+盈利增长 | 亏损+高质押+ST风险 |

### 5.2 操作决策矩阵

| 技术面 | 资金面 | 消息面 | 建议 |
|--------|--------|--------|------|
| 强势 | 强势 | 正面 | 积极做多 |
| 强势 | 强势 | 中性 | 做多，关注消息变化 |
| 强势 | 弱势 | 正面 | 轻仓试多，等资金确认 |
| 强势 | 弱势 | 中性 | 观望，等资金信号 |
| 弱势 | 强势 | 正面 | 关注，可能反转 |
| 弱势 | 弱势 | 任何 | 规避 |

### 5.3 风险控制

- **单只仓位**：不超过总资金20%
- **止损纪律**：跌破关键支撑位果断止损
- **不追高**：错过启动点不追，等回调机会
- **避开雷区**：ST/高质押/业绩暴雷股不碰

## 六、报告生成

分析完成后，按 `assets/report-deep-analysis.md` 模板生成结构化报告，包含：
1. 个股基本信息
2. 四维度分析结果
3. 综合评估
4. 操作建议（买入/观望/卖出 + 建议价位 + 止损位）
5. 风险提示
