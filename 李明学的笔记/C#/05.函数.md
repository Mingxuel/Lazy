# <span style="color: #FFA000;">函数</span> 
### 函数
```c#
int x = 10; // must assign out of function
int func(ref int x, out int y) {
    y = 10; //must assign out int type
}
int func(int x = 10);// Optional Parameters | Default Parameter Values
int func(params int[] args); // Have only one variable arguments
///////////////////////////////////////////////
int func (int x);
int func(int x, int y); //Function Overloading | Method Overloading
```
