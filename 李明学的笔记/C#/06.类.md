### 类声明
```c#
class Program {
    private int id; // class field
    
    public int ID { //class property
        get { return this.id; }
        private set { this.id = value; }
    }

    public Program() { // Default constructor
        ;
    }

    ~Program() { // Destructor
        ;
    }

    void function SetID(int id) { // class method
        this.id = id;
    }
}
```
### 类和结构体区别
```c#
        struct                  class
        值类型                  引用类型
        不可继承                可继承
        无析构函数              有析构函数
    字段声明时不能初始化      字段声明时可初始化
     System.ValueType        System.Object
```

### 多态
```c#

        return 0;
    }

        return 0;
    }
}
```
