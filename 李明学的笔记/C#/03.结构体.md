# <span style="color: #FFA000;">结构体</span> 
### 结构体
```c#
struct Test {
    public string key;      // Struct variables cannot be initialized when declared
    public string value;
    // we don't need create default constructor in struct
    public Test(string key, string value) {
        // must init all members in constructor
        this.key = key;
        this.value = value;
    }
}
```
