# <span style="color: #FFA000;">数组</span> 
### 一维数组
```c#
int[] arr = new int[10];
string[] arr_str = {"A" , "B", "C"};
int len = arr_str.Length;
```
### 二维数组
```c#
int[，] arr = new int[10，10];
string[,] arr_str = {{"A" , "B", "C"}， {"D" , "E", "F"}};
int len_row = arr_str.Length(0);
int len_column = arr_str.Length(1);
```
### 交错数组
```c#
int[][] arr = new int[3][] {new int[] {1, 2},
                            new int[] {3, 4, 5},
                            new int[] {6, 7, 8, 9}};
```
