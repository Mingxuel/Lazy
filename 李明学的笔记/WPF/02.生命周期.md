# <span style="color: #FFA000;">生命周期</span> 
### Application生命周期
```c#
base.OnStartup() //启动
base.OnActivated() //激活
base.OnDeactivated() //非激活
base.OnExit() //退出
```
### 窗体的生命周期
```c#
this.SourceInitialized // 资源初始化，比Loaded还要早
this.Activated //激活时
this.Loaded //窗体加载时
this.ContentRendered //加载完成且渲染完毕
this.Deactivated //非激活时
this.UnLoaded //窗体释放时
this.Closing //窗体关闭时 
this.Closed //窗体关闭完成
```
### 程序退出方式
```c#
App.xaml
    ShutdownMode="OnMainWindowClose"
    ShutdownMode="OnLastWindowClose"
    ShutdownMode="OnExplicitShutdown"// Need to be manually exit
Application.Current.Shutdown(); // 主窗口关闭，后台线程全部关闭后才可以退出
Environment.Exit(0); //直接终止进程，可出发AppDomain.ProcessExit，稍微优温柔一点
Process.GetCurrentProcess().Kill(); //强制退出，很粗鲁
Environment.FailFast("Unnormal exit"); // Throw exception
```
